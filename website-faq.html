FAQ

よくある質問

料金・支払い・制作・公開後の更新について、よくある質問をまとめています。質問をタップすると回答が開きます。

制作料金はいくらですか？

標準料金は、1ページ完結サイト¥15,000〜、セミオーダーサイト¥22,000〜、フルオーダーサイト¥30,000〜です。必要なページ数や機能を確認したうえで最終金額を確定します。

店舗・企業も標準範囲なら上記プランで相談できます。EC、大規模予約、会員機能など特殊な機能や大規模構成は個別見積りです。

なぜこの価格で作れるのですか？

ホームページ制作は内容によって金額差が大きいですが、参考例として、Web幹事ではライトな企業サイトを10万〜50万円、フリーランスへの依頼を10万〜20万円程度の目安として紹介しています。クラウドワークスでは、TOP＋下層2ページのデザイン・コーディングで20万円〜が発注相場の一例です。

SHO WEB SUPPORTの標準プランは1ページ完結 ¥15,000〜 / セミオーダー ¥22,000〜 / フルオーダー ¥30,000〜。一般的なホームページ制作相場より安価な価格設定です。

価格を抑えられる主な理由は、独自の制作システムと個人運営により、営業・外注・管理部門・オフィスなどの中間コストを抑えていることです。

大規模なシステム開発、EC、複雑な予約・会員機能、大規模なマーケティング設計などは標準料金の対象外です。必要な範囲を絞ることで、制作・公開後の更新まで低価格にしています。

公開後30日間の無料調整では何ができますか？

全プランに公開後30日間の無料調整期間があります。

1ページ完結サイトは、1ページ内の色・写真・文章・リンク・配置などを調整できます。セミオーダーはテンプレートの骨格は変更できませんが、その骨格内の写真・文章・色・リンクなどを調整できます。フルオーダーは当初の制作範囲内であれば、骨格の再調整や、依頼時に入れ忘れていたページの追加相談まで対応します。

大規模な機能追加、EC、予約・会員機能など、当初の制作範囲を超えるものは別途お見積りとなります。

テンプレートは他の人と被りませんか？

セミオーダーは基本レイアウトを共有するため、骨格は同じになります。ただし写真・文章・ロゴ・配色・リンクを差し替えるため、見た目の印象は大きく変わります。レイアウト自体から他と被らない形にしたい場合は、フルオーダーサイトをおすすめします。

他のホームページ制作会社と何が違いますか？

SHO WEB SUPPORTは、小〜中規模のホームページを、分かりやすく・更新しやすく・低コストで持ちたい方向けのサービスです。

窓口から制作・公開後の更新まで基本的に同じ担当者が対応し、LINEで相談できます。バンド・アーティスト・個人活動だけでなく、飲食店、アパレル、小売、サロン、各種サービス、企業サイトにも対応します。

公開後も、専門知識がなくてもスマホから更新依頼できる仕組みを重視しています。一方で、大人数の制作チームによる戦略設計、広告運用、大規模システム開発まで含めた総合的な制作会社とは役割が異なります。

企業やお店のホームページも依頼できますか？

はい。飲食店、アパレル、小売店、サロン、各種サービス、事務所、企業・法人などもご相談いただけます。

店舗情報、メニュー・商品紹介、会社案内、採用情報、お問い合わせ導線など、目的に合わせて構成します。標準的な紹介サイトなら1ページ完結 / セミオーダー / フルオーダーから選べます。EC、大規模予約、会員機能など特殊な機能は内容を確認して個別にお見積りします。

支払い方法は何がありますか？

現在は銀行振込を基本としています。振込先は最終金額確定後に個別にご案内します。振込手数料はお客様負担です。

PayPayやクレジットカードは使えますか？

現在は対応していません。今後、必要に応じて決済方法を追加する可能性があります。

依頼前に相談だけでもできますか？

可能です。「こんなサイトにしたい」「自分の場合はいくら？」など、まだ依頼を決めていない段階でもLINEから相談できます。

何を用意すればいいですか？

サイト名、掲載したい文章、写真、ロゴなどをヒアリングフォームから送っていただきます。内容が固まっていなくても、希望の雰囲気や参考サイトなどから相談できます。

スマホだけでも依頼できますか？

できます。ヒアリングや公開後の定型更新は、スマホから使いやすい形を前提にしています。

無料URLと独自ドメインは何が違いますか？

無料URLでもサイトの機能や表示品質は変わりません。 個人・バンド・アーティストなどは、まず無料URLで始めても問題ありません。

独自ドメインは abcband.com のような専用URLです。短く覚えやすく、店舗・企業・公式サイトとしての印象を整えやすいメリットがあります。

SHO WEB SUPPORTでは、独自ドメインの設定代行を¥5,000〜＋ドメイン取得・更新の実費で対応します。取得先の案内、DNS設定、GitHub Pagesへの接続、HTTPS確認まで行います。ドメインは原則としてお客様名義で取得します。

デメリットとして、ドメイン会社へ毎年の更新費用がかかり、更新を止めるとそのURLを使えなくなる可能性があります。ドメイン種類・契約会社・既存ドメインの移管状況によって費用は変わるため、実費と最終金額は事前にご案内します。

セミオーダー / フルオーダーの3か月無料は自動で有料になりますか？

自動で有料プランへ切り替わることはありません。 無料期間終了後は料金が発生しない状態に戻り、必要な場合だけLIVE更新・通常更新・定型更新使い放題から改めて選べます。キャンペーンは申込時に表示がある方が対象で、予告なく変更・終了する場合があります。

公開後にLIVEや写真を追加できますか？

できます。LIVE更新は¥1,000/回、通常更新は¥2,500/回、定型更新使い放題は¥7,000/月です。新規ページ追加や大きなデザイン変更、特殊機能は別途相談となります。

制作にはどのくらいかかりますか？

ページ数、写真・文章の準備状況、希望する機能によって変わります。内容確認時に目安をご案内します。
